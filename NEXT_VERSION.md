# Localz V2 roadmap

Included in this starter:
- Original Localz quick-commerce UI
- Home, Explore, Cart, Checkout, Orders, Account
- Product/category structure
- Cloud APK build workflow for GitHub Actions

Production integrations to add next:
- Firebase phone/email authentication
- Firestore/PostgreSQL backend
- Razorpay/Cashfree payments
- Maps/live delivery tracking
- Store dashboard and inventory
- Delivery-partner app
- Admin dashboard
- Push notifications
- Coupons, wallet, refunds and order cancellation
